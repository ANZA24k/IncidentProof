Notes / Description (under 1000 characters):

IncidentProof verifies software incident claims against immutable public evidence. Operators commit the statement, timeline, root cause, remediation and SHA-256/byte-length manifests. GenLayer validators independently re-fetch authenticated snapshots and assess claim support, contradictions, sufficiency and trustworthiness. Deterministic rules derive VERIFIED, PARTIALLY_VERIFIED, DISPUTED or INSUFFICIENT and enforce authorization, deadlines, replay prevention and immutable final history. Stable Studionet deployment and a real Full Consensus verification finalized successfully. The disclosed synthetic fixture supports all three claims internally but correctly returns INSUFFICIENT because fabricated records are not trustworthy operational evidence. Includes 31 passing focused tests, GenVM lint/validation, passing CI, source readback and live verification records.
